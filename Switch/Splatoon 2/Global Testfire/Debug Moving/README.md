## Debug Moving

Reimplements the Debug Moving feature from the debug build in retail.

Allows you to freely move in the air, basically like NoClip.

You can also fly up/down with `Right Stick Up/Down`. While in squid form, you'll move/fly much faster.

You can pass through collision and be invincible to damage.

A few other gameplay behaviors are changed; see the source code for full details.

Press `Minus` to toggle.

To disable the debug print on-screen when enabled, use the [`Disable Debug Text Draw`](https://github.com/RoGamer97/ASM-Cheats-and-Patches/tree/main/Switch/Splatoon%202/Global%20Testfire/Disable%20Debug%20Text%20Draw) patch.

If you experience issues building from .pchtxt on console, use .ips instead.
