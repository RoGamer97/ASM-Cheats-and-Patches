## Display Dirty (D) Debug Mark

Reimplements the Debug Dirty (D) Debug Mark feature from the debug build in retail.

When using debug features at least once, a red (D) mark will be shown on the top left of the screen, indicating that debug was used, so the game is "dirty".

If you experience issues building from .pchtxt on console, use .ips instead.
