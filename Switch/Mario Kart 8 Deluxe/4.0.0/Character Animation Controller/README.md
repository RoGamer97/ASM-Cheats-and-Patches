## Character Animation Controller

Allows controlling character animations.

### Animation Repeat Mode
Hold `Right Stick In` and press `Left Stick In` to toggle animation repeat mode.

When enabled, hold `Right Stick In` and push `Left Stick Left/Right` to cycle through animations.

### Animation Control Mode
When animation repeat mode is enabled, press `Right Stick In` to enter animation control mode. 

In this mode, the current animation will freeze and you can move through its keyframes by holding `Left Stick In` and pushing `Left Stick Left/Right`. 

You can also change the facial animation by holding `X` and pressing `D-Pad Left/Right`.
