## About

This is a collection of public ASM cheat codes, patches, and hacks for various Nintendo console games.

You'll find a variety of codes, including quality-of-life improvements, gameplay fixes, debug features, experimental and fun codes, and much more.

It only includes codes made by me.

## Update in Progress

> [!IMPORTANT]
> As of **May 27, 2026**, this repository is currently being updated. Many existing codes are being rewritten and improved.

Source code is also being added over time.

The update is being done per game. Once a game's codes have been fully updated, they will be pushed all at once rather than in parts. However, there may still be additional changes after the initial update has been pushed.

New codes created after the updates will continue to be added as usual.

## Source Code (WIP)

> [!NOTE]
> Source code is currently being added and is still a work in progress.

The goal is to help others understand how these codes work and how they modify the game. The included source code can also serve as a reference for understanding and creating custom ASM hooks, also known as [code caves](https://gamehacking.academy/pages/2/06/).

Source code is only included for codes that use hooks. If a code only has instruction patches, it will not have source code or an explanation, unless at least one hook is present.
