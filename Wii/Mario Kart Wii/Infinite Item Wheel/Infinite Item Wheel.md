## Infinite Item Wheel

Makes you always have items. You can change what item to have by pressing buttons. The code is customizable to choose what controller and items you want, for all items in the game. You can assign a button to give you "Empty item", which will clear your slot and allow you to obtain normal items from box as if you disabled the code.

Note that the code is designed to only one controller at a time, so for example, if set to Nunchuk, the code will only work if using Nunchuk. Code will work individually for all players in Multiplayer, as long as they are using the controller that the code is set to (Example: 4P Multiplayer, the players using Nunchuk will be affected).

Unlike every other Always Have Item/Item Wheel hack, this version doesn't cause Triple Items to "corrupt" and eventually crash when dropped, because it gives items the correct way. 

You can either manually modify the Gecko code by replacing the values below or build it from source (Highly recommended).

If you want, you can use Item Cycler (Debug and Infinite) instead, which cycle through items with D-Pad and works for all controllers by default (Except Wii Wheel).

Or to always have the same item (Infinite), use either Always Have Item (Unique Per Player) or Always Have Item (Local Players).
