## Balloon Start/Respawn Amount Modifier 

Allows you to modify the amount of balloons players start and respawn with.

<details>
<summary>NTSC-U</summary>

X: Start Amount
Y: Respawn Amount

Max is 5

```
04865768 3900000X
04534348 3900000Y
```
</details>
