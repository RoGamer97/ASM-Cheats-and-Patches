## Auto-Accelerate (Classic and GCN Only)

Makes it so you auto-accelerate, similar to Mario Kart 8 Deluxe's Auto-Accelerate option.
During countdown, you'll still need to press A to build a rocket boost, but during the race, you'll always be accelerating. Drift with R, brake and reverse with B. Standstill miniturbo by holding B.

You'll also be able to drift or standstill miniturbo if holding B when A is also held.
YOU WILL NOT BE ABLE TO PERFORM A RESPAWN BOOST WITH THIS CODE, SO I RECOMMEND USING CLF78'S ALWAYS GET RESPAWN BOOST CODE (https://mariokartwii.com/showthread.php?tid=1821)
