## Minimap Character Icon Rotates with Kart Direction

Makes minimap character icons rotate based on the direction the kart is facing, the same way the searchlight rotates.

There are two versions of this code:

* Local players only: Only local player's character icons rotate.

* Everyone: Everyone's character icons rotate

Looks cool when used with Disable Minimap Searchlight code.
