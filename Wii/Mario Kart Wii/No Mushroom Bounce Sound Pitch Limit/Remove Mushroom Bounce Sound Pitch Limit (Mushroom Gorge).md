## Remove Mushroom Bounce Sound Pitch Limit (Mushroom Gorge)

Removes the pitch limit from the Mushroom object in Mushroom Gorge slot.

By default, after 3 bounces, the pitch is no longer increased. This code will increase the pitch regardless of how many times you bounce.

<details>
<summary>NTSC-U</summary>

```
04702640 60000000
```
</details>

<details>
<summary>PAL</summary>

```
04708FE4 60000000
```
</details>

<details>
<summary>NTSC-J</summary>

```
04708650 60000000
```
</details>

<details>
<summary>NTSC-K</summary>

```
046F738C 60000000
```
</details>
