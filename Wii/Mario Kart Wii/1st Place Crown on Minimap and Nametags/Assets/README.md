Apply custom assets to your own Race.szs by replacing the original files with the ones provided.

For usage with 1st Place Crown on Minimap/Nametag or Show Kart Status Effects on Minimap.

Note that if you're only using Crown in 1st Place on Nametags, you only need these files:
* game_image\timg\crown.tpl
* game_image\blyt\chara_name.brlyt

And if not using Crown in 1st Place on Nametags, you don't need game_image\blyt\chara_name.brlyt

But you MUST add all other files if you're using either Crown in 1st Place on Minimap or Show Kart Status Effects on Minimap, else it will crash.

If you want to use Flag/FC Display with 1st Place Crown on Nametags, either add the layouts correctly to the Flag mod BRLYT or do the opposite (Add the flag and FC layouts to the crown mod BRLYT).

You can use these files without using the code - it will only show if you use the codes.

Enjoy!
