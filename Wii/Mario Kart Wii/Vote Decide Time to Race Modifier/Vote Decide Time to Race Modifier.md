## Vote Decide Time to Race Modifier

Allows you to modify the duration of the wait to the race after the roulette has been decided.

<details>
<summary>NTSC-U</summary>

XX: Seconds in Frames

Original is B4 (180 frames, 3 seconds)

```
04612868 386000XX
```
</details>

<details>
<summary>PAL</summary>

XXXX: Seconds in Frames

Original is 00B4 (180 frames, 3 seconds)

```
04643C88 386000XX
```
</details>
