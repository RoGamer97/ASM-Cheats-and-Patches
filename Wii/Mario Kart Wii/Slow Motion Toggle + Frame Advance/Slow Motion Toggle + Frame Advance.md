## Slow Motion Toggle + Frame Advance

Allows you to toggle two slow motion modes, freeze the game, and frame-advance by pressing a button. It’s a very fun code to experiment with, you can “TAS” and even do Rapid Fire Hop Abuses. This is a recreation of the Debug Slow Motion found in the Mario Kart 8 Deluxe Prototype.

When in a race, toggling the code on will freeze the game (starts in Frame Advance Mode). Press the Change Mode button to change the mode to SLOW (2x slower), press it again to change it to SUPER SLOW (15x slower). Press the Frame Advance button to change mode to Frame Advance Mode, where the game is frozen and you can advance frames by pressing the button that was used to enter this mode. Press the toggle button to disable the code.

Code only works in-game (not in menus). Code is INCOMPATIBLE with the Online Pause Menu code because of the hook location.

Here are the toggle buttons and mode change buttons for every controller:

Wii Wheel:
Hold A and press MINUS To toggle on/off
MINUS Frame Advance Mode
A Change Mode

Nunchuk:
Hold C and press Down to toggle on/off
D-Pad Down Frame Advance Mode
C Change Mode

Classic:
Hold X and press ZR to toggle on/off
ZR Frame Advance Mode
X Change Mode

GCN:
Hold Z and press Y to toggle on/off
Y Frame Advance Mode
Z Change Mode
