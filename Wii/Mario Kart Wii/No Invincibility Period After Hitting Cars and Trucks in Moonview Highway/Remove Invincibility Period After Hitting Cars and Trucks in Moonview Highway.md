## Remove Invincibility Period After Hitting Cars/Trucks in Moonview Highway

Removes the invincibility period that the player has against the cars and trucks in Moonview Highway if getting hit by them. This only happens in the Moonview Highway slot and code can be written to only affect specific custom track slots. The timer can be configured by modifying the compare next to the address of my code.

<details>
<summary>NTSC-U</summary>

```
046C85CC 38000200
```
</details>

<details>
<summary>PAL</summary>

```
046D740C 38000200
```
</details>

<details>
<summary>NTSC-J</summary>

```
046D6A78 38000200
```
</details>

<details>
<summary>NTSC-K</summary>

```
046C57B4 38000200
```
</details>
