## SkipFERaceID

Changes the forced race event ID used for SkipFE races.

<details>
<summary>Show code</summary>

Modify the Xs with the race ID string. Read the example for reference

```
065B02FC 00000008
XXXXXXXX XXXXXXXX
```
</details>

<details>
<summary>Code Example</summary>

Forces "gpmm_8p"

```
065B02FC 00000008
67706D6D 5F387000
```
</details>
